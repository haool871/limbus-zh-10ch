## 一、先装零协会汉化（必做）

本仓库是**补丁**，不是完整汉化包。**必须**先装好零协会汉化，再装本补丁。

官方安装指南：<https://www.zeroasso.top/docs/install/autoinstall>



> ⚠️ 请务必装**最新版**零协会汉化。本补丁只补「零协还没有的部分」，
> 若零协包太旧，补丁里那部分文件的内容可能比零协新版还旧。

## 三、安装（三分钟）

### 第 1 步：找到游戏目录

**Windows（Steam）**：在 Steam 里右键《Limbus Company》→ 管理 → 浏览本地文件，
就打开了游戏根目录。

**Linux / Steam Deck**：

```
~/.local/share/Steam/steamapps/common/Limbus Company/
```

### 第 2 步：进入语言目录

在游戏根目录里依次进入：

```
LimbusCompany_Data/Lang/LLC_zh-CN/
```

这个目录里有 `StoryData`、`RPGSystem` 等文件夹——说明零协会汉化装好了。

### 第 3 步：把补丁复制进去

| 系统 | 操作 |
| --- | --- |
| **Windows** | 打开本补丁的 `patch` 文件夹 → **Ctrl + A** 全选 → **Ctrl + C** → 回到 `LLC_zh-CN` → **Ctrl + V** → 弹窗选**「替换目标中的文件」** |
| **Linux / Steam Deck** | 在补丁目录里执行下面这行 |

```bash
cp -r patch/. "/你的路径/steamapps/common/Limbus Company/LimbusCompany_Data/Lang/LLC_zh-CN/"
```

### 第 4 步：启动游戏

直接开游戏即可，**不需要**在游戏里重新选语言。

## 四、检查有没有装对

装好后进入游戏，以下位置应该显示中文：

| 位置 | 看什么 |
| --- | --- |
| 主界面 | 菜单文字 |
| 商城 / 编队 | 人格、技能的**名称与描述** |
| 剧情 | 对话文本 |

只要有一处显示英文或韩文，先检查：

1. `LLC_zh-CN` 里是否真的有 `StoryData`、`RPGSystem` 两个**文件夹**
   （只有一堆散装 json 说明文件夹没复制过去，回第 3 步重做）
2. `LimbusCompany_Data/Lang/config.json` 里的语言是否为 `LLC_zh-CN`
3. 字体有没有装

## 五、卸载

| 需求 | 做法 |
| --- | --- |
| **彻底删汉化** | 删掉整个 `LimbusCompany_Data/Lang/` 文件夹，游戏回到韩/英/日原版 |
| **只撤本补丁** | 用零协会汉化包里的同名文件覆盖回去；零协会没有的那些文件直接删掉 |
| **恢复游戏原状** | 在 Steam 里右键游戏 → 属性 → 已安装文件 → 验证文件完整性 |

## 七、常见问题

**Q：`patch` 文件夹是空的？**

说明这一版还没有新的待补内容——零协会汉化当时已经覆盖了游戏里全部文本。
等游戏更新出零协尚未汉化的新内容时，这里会出现文件。届时本页会同步更新。

**Q：为什么不直接做成完整汉化包？**

零协会的汉化更完整、更权威，而且持续更新。重复劳动没有意义，
所以本仓库只补它还没做到的部分。

**Q：装了补丁后文本反而变旧了？**

零协包不是最新的。本补丁的部分文件基于某个零协版本，
请更新零协会汉化到最新版后重装本补丁。

**Q：想自己翻译 / 想了解这套流程怎么做的？**

翻译流程、术语库、角色口吻规范都在知识库仓库：
<https://github.com/haool871/Limbus-Company-Chapter-10-Week-1-Chinese-Localization-Share>
（该仓库主要是**给翻译者看的**，普通玩家不需要。）

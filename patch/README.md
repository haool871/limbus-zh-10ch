# 本目录 = 补丁本体

**这里的文件就是要复制进游戏的东西。**

## 怎么用

把本目录**全选**，复制到游戏的

```
LimbusCompany_Data/Lang/LLC_zh-CN/
```

弹窗选**覆盖**。详见仓库根目录的 [README](../README.md)。

## 目录为什么是空的

本仓库是**零协会汉化的缺口补充包**：只放零协**尚未汉化**的游戏文本。

- 若本目录为空 → 当前零协汉化已覆盖游戏全部文本，**无需打补丁**。
- 游戏更新、零协还没跟上时，这里会出现对应文件，并打上版本 tag。

## 给翻译者的说明

**不要直接手改本目录的文件。** 这里是每次批次的**发布快照**，
上游真正的修改源是知识库仓库里的活动批次：

- 知识库：<https://github.com/haool871/Limbus-Company-Chapter-10-Week-1-Chinese-Localization-Share>
- 流程规范：该仓库 `knowledge-base/workflow/版本更新流程.md`

正确顺序是：在知识库里建批次 → 翻译 → 审校 → `batch verify` 通过
→ `batch export` 导出交付目录 → 把交付目录内容同步到本目录 → 提交并打 tag。

理由：直接改这里会绕过验收（标记/占位符/审校绑定检查），
下一次发布又会被新的交付快照覆盖，改动就丢了。
